Eigenvectors: the directions a matrix doesn't turn

A matrix A moves almost every vector to a new direction. A few special vectors only get stretched, shrunk or flipped and stay on their own line. Those are the eigenvectors, and the stretch factor is the eigenvalue λ.

Why do we solve det(A − λI) = 0?

If Av = λv then (A − λI)v = 0. A non-zero v can be sent to 0 only if the matrix A − λI squashes the whole plane onto a line, i.e. its area-scaling factor det(A − λI) is 0. Slide λ and watch the unit square under A − λI. It flattens exactly at the eigenvalues, and the green direction is the one that gets crushed to zero.

The maths

A non-zero vector X is an eigenvector of a square matrix A if

AX = λX,   X ≠ 0

for some scalar λ, the eigenvalue. Rearranging: (A − λI)X = 0. This homogeneous system has a non-trivial solution only when A − λI is singular, which gives the characteristic equation

|A − λI| = 0

For a 2×2 matrix A = [a b; c d] it becomes

λ² − (a + d)λ + (ad − bc) = 0

i.e. λ² − (trace A)λ + |A| = 0. So λ₁ + λ₂ = trace A and λ₁λ₂ = |A|, which is a quick check in exams. For each λ, solve (A − λI)X = 0 for X.

Where it's used: natural frequencies and mode shapes of vibrating beams and buildings, principal stresses in strength of materials, stability of control systems, and Google's PageRank.

Worked example

Find the eigenvalues and eigenvectors of A = [2 1; 1 2].

1. Characteristic equation. |A − λI| = (2 − λ)² − 1 = λ² − 4λ + 3 = 0.

2. Eigenvalues. (λ − 3)(λ − 1) = 0, so λ₁ = 3, λ₂ = 1. Check: 3 + 1 = 4 = trace, 3 × 1 = 3 = |A|.

3. λ = 3. (A − 3I)X = 0 gives −x + y = 0, so y = x. X₁ = k(1, 1).

4. λ = 1. (A − I)X = 0 gives x + y = 0, so y = −x. X₂ = k(1, −1).

5. Picture. Any vector on the line y = x is stretched 3 times. Any vector on y = −x is unchanged. Every other vector gets turned.

Try this

1. In the worked example, put v on y = x and drag it longer. Does λ change?

No. Av = 3v for every vector on that line. An eigenvector is really a direction. That's why textbook answers say k(1, 1): any non-zero multiple works.

2. Load [1 2; 2 1]. One eigenvector has Av pointing the opposite way to v. Is it still an eigenvector?

Yes. On the line y = −x, Av = −1·v. It stays on the same line, just flipped, so λ = −1. Negative eigenvalues mean "flip and scale".

3. Load the 90° rotation and sweep v all the way round. Does Av ever line up with v?

Never. Every vector is turned by 90°, so no real direction survives. The characteristic equation λ² + 1 = 0 gives λ = ±i. Complex eigenvalues signal rotation, not "no answer".

4. Load the shear [1 1; 0 1]. How many eigen-lines are there?

Only one, the x-axis. λ = 1 is a repeated root but gives only one independent eigenvector, so a repeated eigenvalue does not guarantee two eigenvector directions.

5. Make the matrix symmetric (b = c) with any values. What angle do the two eigen-lines make?

Always 90°. Real symmetric matrices have real eigenvalues and orthogonal eigenvectors. This is why principal stress directions are perpendicular.

6. Start v anywhere off the eigen-lines and keep pressing "v ← Av". Where does v end up?

It swings onto the eigen-line with the largest |λ| (for [2 1; 1 2], the line y = x). Each press multiplies the λ = 3 part by 3 and the λ = 1 part by 1, so the first wins. This is the power method for finding the dominant eigenvalue.

Common mistakes

  • Writing |A − λ| = 0. You subtract λ only on the diagonal: A − λI.
  • Thinking the eigenvector is unique. Any non-zero multiple k·X is also an eigenvector. X = 0 is never an eigenvector, even though A·0 = λ·0.
  • Expecting Av to point the same way as v. "Same line" is enough: λ can be negative (Av flipped) or zero (Av = 0).
  • Assuming every 2×2 matrix has two real eigenvector directions. Rotations have none and shears have only one.
